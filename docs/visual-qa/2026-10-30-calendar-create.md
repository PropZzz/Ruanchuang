# 新增普通日程与日历卡片验证

## 排查结论

新增保存的 POST /schedule 和返回日历刷新链路已存在，但发现两处实际问题：

1. 新增抽屉的 selectTag 只切换可见配色，没有同步 active-tag，保存时仍读取初始“跨部门协同”。
2. 新建日程固定提交 color=0；日历根据不存在于 ScheduleEntry API 的 status/isUrgent 字段选主题，导致真实日程基本都渲染为灰色。手机还有将普通卡片背景覆盖成白色的规则。

## 修复

- 标签选中态、aria-pressed 与提交字段保持一致。
- themeFor 从实际持久化的 tag/color 选择原演示主题，新建时保存相同的 ARGB color；已存在 color=0 的记录也能按标签显示。
- 使用原模板的深绿、浅蓝、灰色与浅灰色，恢复卡片分类图标、时间、标题、标签胶囊和时长。不会伪造“已完成”或优先级状态。
- 评审 #163d3d，协同 rgba(98,161,254,.4)，编码 #e9e7ed，调研 #efedf3；对应前景与标题颜色来自原模板。依据：Git d705e6c 的 smart-calendar 演示卡片。
- 保持原页面、导航、抽屉和当前时间指示线。
