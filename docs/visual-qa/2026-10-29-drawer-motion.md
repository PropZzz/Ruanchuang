# 二级抽屉动效排查（2026-10-29）

目标：打开二级内容时保留来源页面，关闭时连续回到原画面；快速连续点击不跳帧、不把旧请求覆盖到新页面。

## 逐项处理

| 界面 | 原问题 | 处理与验证 |
| --- | --- | --- |
| 新增日程 | 整页切换，原页面被遮盖/替换 | 桌面右侧抽屉、手机底部抽屉；保留来源文档和背景；验证关闭按钮及快速反向 |
| 插入紧急任务 | 与新增日程一样走整页过渡 | 公共抽屉动效；验证遮罩、返回、快速反向 |
| 微任务录入 | 抽屉本身未独立动画 | 公共抽屉动效；验证 Escape、焦点限制、返回与文档复用 |
| 日程详情 | 卡片只修改子 iframe 路由；加载/编辑状态可能同时显示 | 父路由携带 id，接入原详情组件；明确 hidden 样式；验证真实卡片入口及详情标题 |
| 微任务详情 | 缺少本地字体/Tailwind 配置，且子页面自行导航 | 补齐现有样式依赖；父路由与关闭统一管理；验证真实卡片入口和浏览器返回 |
| 系统偏好设置 | 关闭直接删除 DOM；重开重载；慢 API 阻塞操作 | 退出动画结束后隐藏并复用文档；数据加载与动画分离；验证慢响应、快速反向与跨断点复用 |
| 目标详情 | 独立 CSS 开关无法连续反向，公共顶栏被 iframe 画布覆盖 | 接入公共控制器，背景透明并保留 shell；验证原生关闭按钮、Escape 和快速反向 |
| 智能拆解弹层 | 开关仅切透明度，焦点和背景交互未统一管理 | 16px 位移配合遮罩渐变；验证 Escape、关闭后恢复交互 |

## 实现约束

- 公共控制器：`web/stitch/drawer-motion.js`，只动画 transform 与遮罩 opacity，结束后撤销 will-change。
- 完整打开约 300ms、关闭约 220ms；中断后读取当前绘制位置，按剩余距离继续，不重置到起点。
- 保留父页面 DOM、草稿和滚动位置；退出动画完成后才释放遮罩与背景交互。
- 保留键盘焦点限制和焦点恢复；支持系统“减少动态效果”，动画进行中切换该偏好也能完成清理。
- 新控制器与宿主、路由脚本一起生成内容版本文件名，避免旧缓存脚本混用。
