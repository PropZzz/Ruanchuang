# 账号入口统一

用户要求保留“我的”账号系统；右上角设置保留非账号功能，沿用现有外观。

## 实施范围

- 删除桌面、手机设置抽屉中的“账户与多用户管理”区块，移除对应账号按钮绑定和资料填充逻辑。
- “我的”保留切换账户，在原卡片操作区接入修改昵称和退出登录，复用 `/auth/profile`、`/auth/logout`。游客显示登录／注册入口。
- 保留设置中的外观、语言、通知、引擎偏好和移动端本地备份／诊断功能及原来的未接入提示。
- 设置图标统一打开设置抽屉，避免页面内设置按钮跳转到“我的”。
- 修复页面宿主只认旧 Tailwind 模板标记、导致独立样式登录页加载失败的问题：仅对 login 路由允许认证页面标记与真实提交控件作为页面识别依据。
- 昵称编辑支持取消、Escape、重复打开和回车保存，关闭后清理对话框和样式。

## 验证方法

`tools/check_stitch_account_settings.mjs` 使用真实 FastAPI 与临时 SQLite，桌面和手机分别验证昵称修改和取消、刷新持久化、设置中无账号按钮、其他设置保留及保存、切换账号和返回、退出后令牌失效、游客入口。支持 `--url` 验证公网静态前端；所有 API 请求转发到本地隔离后端，不写正式业务数据。

截图输出到 `build/account-settings-qa`，报告输出到 `build/reports/account-settings.json`。

设计检测以降级正则模式执行，仅提示手机设置原有字号层级警告；未改变原有字体与配色。
