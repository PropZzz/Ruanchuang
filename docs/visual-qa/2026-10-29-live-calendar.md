# 智能日历接入真实日期与账号日程

用户确认范围：真实日期、当前账号日程，支持日/周/月切换与新增编辑后的同步显示。

## 实现

- `web/stitch/calendar.js` 独立负责日期、重复规则、时间布局、视图和数据状态；桌面、手机共用同一数据逻辑，恢复并增强原桌面控制台、指标条、时间地图、右侧救援摘要，以及手机日期胶囊、负荷条、纵向任务列表和救援胶囊；保留既有颜色/字体/间距/导航/抽屉。
- 桌面默认周视图，手机默认日视图；支持上一/下一周期、今天与原生日期选择器。周一为周起点，月视图使用完整六周网格。
- 通过现有鉴权 `GET /schedule` 读取当前账号集合，仅填充模板的日期、日程、统计和状态节点，不再重建整页 DOM。清除演示日程和伪造指标，未计算的救援策略保留原卡片外观并明确等待计算。无数据、未登录、断网、重试均有对应状态。
- 桌面默认保留原 08:00–21:00 时间地图，真实日程或当前时刻超出此范围时扩展时轴，可覆盖 00:00–24:00；重叠日程分列，跨午夜拆分为当日片段；手机继续使用原来的纵向任务列表。当前时间线仅在可见页面更新。
- 重复规则与现有 Dart 客户端一致：每天、每周、逐月月底夹取，并遵循重复截止日期；旧版 `day=null` 日程保持每天可见。
- 冲突提示根据当前日期实际展开的时段计算，包含重复、旧版浮动与跨午夜记录；既有服务端 `/schedule/conflicts` 只按原始锚点过滤，不能完整表示这些展示时段。
- 新增表单可编辑日期、时间和时长；新增上下文的 day/time 进入路由缓存键，同上下文草稿保留，已提交表单下次打开重置。
- 详情按真实 id 打开。保存/删除后保留来源文档并刷新；替换 PUT 保留未编辑的目标关联、颜色和重复截止日期。编辑重复记录保持当前查看的发生日期；修改或删除作用于整条原始规则，界面明确说明。
- 手机/桌面来回切换复用文档并保持最新日期/视图。后台视图及旧账号的晚到响应不能覆盖当前选择或账号数据。
- 新模块使用内容版本脚本，CSS URL 携带相同版本标记，延续原子发布与旧缓存升级方案。
