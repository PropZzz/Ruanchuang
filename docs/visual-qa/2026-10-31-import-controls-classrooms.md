# 导入控件与课程教室显示

本轮保留既有抽屉宽度、主题色、字体、布局及共享进退动画，只细化导入控件并补充课程信息。

- 文件选择由浏览器默认按钮改为主题上传卡片，显示文件名、格式、大小与更换入口。实际文件对话框继续使用系统能力，文件在本机解析。
- 节次开始/结束时间使用小时、分钟双列浮层，每分钟均可选择，保留手动输入。确认才修改表单，Escape、外部点击取消未确认的选择；支持方向键、Home/End、PageUp/PageDown、Enter、Tab/Shift+Tab。
- 浮层位于抽屉 DOM 内并使用浏览器 top layer，避免滚动区裁剪；可视区定位、焦点循环、隐藏、忙碌和销毁均清理。手动输入保留完整键盘以便在手机输入冒号。
- “上课学习”日程从已有备注读取教室，不迁移或修改存储内容。兼容旧课表“教师 · 教室”、CSV“备注 · 教室 · 教师”和“教室：…”标签；没有教室时不虚构信息。
- 日/周/月卡片在标题下显示教室，甘特左侧摘要显示教室。短于 44px 的桌面时间槽优先保留标题，悬停/聚焦展开教室；辅助名称及详情保留可读信息。属性颜色沿用上课学习主题。
