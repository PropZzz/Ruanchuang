# 日程文件导入验收与发布

## 最终交互

- 入口位于智能日历的“新增普通日程 / 新增日程”抽屉顶部，日历主界面不新增导入按钮，编辑已有日程时隐藏入口。
- 沿用既有字体、主题色、圆角、关闭按钮和共享抽屉动画；导入面板从右侧进入。取消返回原新增表单，保留草稿、日期和开始时间；成功导入返回原日历视图。
- 文件在浏览器本地解析，用户预览、勾选并确认后才请求账号批量接口。原文件不上传到解析服务。
- 支持 XLS、XLSX、CSV、TSV、JSON、ICS。表格字段映射默认折叠；CSV/TSV 可选择 UTF-8 或 GBK/GB18030。
- 导入后的课程采用现有“上课学习”标签配色，教师、教室进入可编辑备注。备注贯穿单条、批量、救援重排和撤销路径。
- 同一来源的稳定 ID 用于精确去重；`createOnly=true` 通过原子 SQL 防止重复导入覆盖用户编辑，不按近似标题合并日程。

## 课表和格式边界

附件 `学生个人课表_8208240318.xls` 识别为 12 条课程安排。测试以 2026-09-07 为首周周一，按测试填写的节次时间展开为 108 次课，包含单/双周和不连续周次。实际使用时必须填写真实首周日期和学校课时，不将测试日期作为默认学期。

表尾“课程设计”缺少星期、节次，界面明确提示另行新增。ICS 暂不展开 RRULE/例外规则，未知或混合时区会报出可读错误；独立事件、跨日、全天和 UTC 时间已有覆盖。文件限制 5 MB，表格最多 5000 行、64 列，最多展开 2000 条，预览每批显示 100 条。
