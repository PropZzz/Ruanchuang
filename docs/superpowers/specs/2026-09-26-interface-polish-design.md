# 时序智配界面 Polish 设计记录

## 范围

本轮以 Stitch Web 入口为准，覆盖全局壳层、移动端首屏「专注」和共享路由注入层。保留现有品牌色、字体、业务文案、页面路由和业务动作，不调整后端契约。

## 视觉与交互方向

- 保留青绿主色与蓝色动作色，用更清晰的层级、间距和状态色区分主要任务、辅助信息和系统提示。
- 固定头部减少垂直占用，底部导航与安全区保持稳定触达区域。
- 主任务卡强化标题、计时器和主动作；次级卡片降低阴影与装饰，让首屏更易扫描。
- 所有图标按钮保留至少 44px 触达尺寸，补齐键盘焦点、悬停、按下和 reduced-motion 行为。
- 长标题、窄屏和滚动内容使用可换行与最小宽度约束，避免布局抖动和遮挡。

## 实施方式

共享 polish 样式放在 `design/stitch-mobile/assets`，由顶层路由在 iframe 加载后注入，覆盖桌面与移动 Stitch 页面；页面源文件只保留页面特有布局。同步脚本将源页面和资源复制到 `web/stitch/mobile`。

## 验证

使用本地 Web 预览检查桌面与移动首屏、主导航和专注动作；读取可访问性树与控制台日志；运行 Stitch 同步检查、Flutter 静态分析和现有测试。
