# 日历文件导入设计

## 目标与边界

在智能日历“新增日程”抽屉内添加“导入日程”入口，不在日历主界面增加按钮。取消导入返回原新增表单并保留草稿，确认成功返回当前日历视图。编辑已有日程时隐藏导入入口。导入时原有账号日程保持不变；用户先在本机选择文件、检查解析结果和预览，再明确确认批量写入。首批格式为传统 `.xls`、`.xlsx`、`.csv`、`.tsv`、`.json`、`.ics`；解析器采用可扩展适配器，未知格式或结构返回可读错误，不猜测后写入。

## 课表与日程映射

附件 `学生个人课表_8208240318.xls` 是传统 OLE `.xls`，工作表是星期×节次矩阵，课程单元含课程名、教师、周次表达式及教室。解析此格式时读取学年学期、星期列、节次行和合并单元格课程块，并将多门课分别识别。导入预览允许用户确认学期第一周周一以及节次到起止时刻的映射；该选择只用于此次导入，不为用户假设学校课时表。

根据第一周日期、星期、节次、周次范围及单/双周条件计算每个实际上课日期。把日期展开为独立日程，保持无课周、单/双周和不连续周次；不转换成会覆盖停课周的通用每周重复规则。课程名映射为标题，课程/学习类别映射为日程标签，节次映射为开始时间和时长；教师及教室映射到新增的可选 `description` 日程备注字段，并在日程详情抽屉中显示。该字段需贯穿 API schema、SQLite schema 初始化/旧库升级、单条与批量 repository 序列化及现有编辑表单，确保已有日程兼容。

CSV/TSV/JSON 读取含有明确日期与时间的逐条日程；ICS 使用本地文本适配器读取事件时间、标题、描述、分类及 UID（受支持的重复规则需展开为有界实例，不支持的规则在预览明确提示）。用常见中英文列名自动匹配标题、日期、开始时间、结束时间/时长、类别/标签、地点和备注，并在预览逐列显示映射和异常。工作簿解析库随本站静态资源发布，文件内容不上传用于解析；CSV/TSV 支持常见 UTF-8 与 UTF-8 BOM，无法正确识别编码时提示保存为 UTF-8。较复杂表格可转成 CSV/JSON 后导入。文件大小、行数和展开实例数应设上限，避免意外卡住浏览器或写入过量数据。

## 导入流程与写入

点击新入口打开与现有 ICS 一致的右侧抽屉。抽屉包含文件选择、格式识别、学期起始周一（仅课程表）、必要列映射、解析错误、日程预览、待导入数量以及取消和确认导入。确认前不调用写接口；取消不会更改日程。根据每个解析结果构造现有 `ScheduleEntryIn` 契约字段，复用账号认证的 `/schedule/batch` 原子批量保存；提交成功后调用日历刷新，在当前视图中看到新日程，并保留用户所选日期和视图。提交失败要显示服务端错误且不报告成功；批量接口的事务语义需先核验，保证整批写入失败时不留部分课程。

每次导入生成稳定的源行/课程实例 ID 规则，提交前与当前账号日程核对精确重复，默认跳过重复项并在预览明确标注；不根据标题近似匹配删除或覆盖用户现有数据。用户可以在导入抽屉取消选中有错误或重复的记录。常规单条导入实例继续使用现有日程详情抽屉编辑和删除。

## 兼容与验证

- 单元测试覆盖 XLS/学期周次展开、单周双周、不连续周次、节次时长映射、CSV BOM/引号/逗号、多列名、JSON 格式、空文件、无效日期、坏行和重复检测。
- 使用提供的中南大学课表验证课程数、星期、节次、教师/教室、周次以及实际日期；通过第一周日期和课时映射预览手工核对，然后确认导入到隔离测试账号。
- 浏览器桌面和手机验证：选择文件、解析预览、映射校正、取消不写入、确认批量导入、重载持久化、日/周/月/甘特显示和已有日程未被覆盖。
- 检查发布清单内含自托管解析库，非工作表文件内容不会被发送到解析服务器。
