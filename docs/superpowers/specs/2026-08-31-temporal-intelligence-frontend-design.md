# 时序智配多端前端设计规范

## 1. 目标与范围

本轮把现有 Flutter 客户端统一为“时间地图”工作台：用户能在同一视觉上下文中看到今天的节奏、精力状态、恢复缓冲和日程冲突，并快速进入日程救援。范围包括全局壳层、专注首页、智能日历，以及其余页面的主题/间距/状态样式统一。

本轮不改变 FastAPI + SQLite 后端、`DataService`/`CompositeDataService` 契约、调度算法、事件记录或本地优先/远端兜底策略。

## 2. 设计原则

- 组件优先使用 Flutter Material 3 原生组件，避免为视觉层引入第三方 UI 依赖。
- 毛玻璃只作为信息分层，不作为低对比度背景；文本、边框、焦点和错误状态必须在浅色/深色模式独立可读。
- 一个页面只保留一个主动作：日历主动作是“添加紧急任务/启动救援”，专注页主动作是“开始/暂停”。
- 状态要诚实区分：加载中、远端可用、本地兜底、无数据、校验错误和冲突错误不可混用。
- 交互控件遵循 44pt iOS / 48dp Android 触控尺寸，桌面端保留键盘焦点和可见焦点环。

## 3. 视觉令牌

### 3.1 颜色

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `canvas` | `#EEF2F0` | `#101B1D` | 页面背景 |
| `ink` | `#183238` | `#E7F0ED` | 主文本/导航 |
| `surface` | `#FFFFFF` | `#1C2B2E` | 卡片基础面 |
| `recovery` | `#83AFA5` | `#8EC8B7` | 能量与恢复缓冲 |
| `deadline` | `#E5A15B` | `#F2B56E` | 截止提醒与计划压力 |
| `risk` | `#C85A4B` | `#F07A6A` | 逾期、冲突、失败 |
| `muted` | `#647579` | `#9CB0AE` | 辅助文字 |

玻璃容器：浅色使用 `surface` 72% 不透明度，深色使用 62%，`BackdropFilter` 模糊 14px，叠加 1px 低对比边框和小范围阴影。主内容不能只依赖透明度区分层级。

### 3.2 字体与尺寸

- 保留仓库内 `NotoSerifSC` 作为品牌标题和区块标题；正文、标签和数据使用系统无衬线回退。
- 正文基线 16sp，辅助文字不低于 12sp，行高约 1.5。
- 间距使用 4/8dp 节奏；页面内边距 16/24/32，桌面工作区最大内容宽度 1320。
- 页面容器圆角 24，组件容器 16，控件 12；不使用无限圆角包裹整段文本。

## 4. 响应式壳层

### 桌面 `>= 1200`

260px 展开侧栏、工作区顶部栏和主内容。侧栏沿用 5 个入口；顶部栏显示当前日期、数据来源状态、主题入口和当前页面标题。日历右侧显示救援摘要。

### 平板 `720-1199`

88px 紧凑 `NavigationRail`，内容区保留顶部栏。救援摘要变为可展开面板，避免压缩时间地图。

### 手机 `< 720`

顶部显示日期、能量和数据来源状态；底部使用 `NavigationBar`。日程编辑、救援方案、字段筛选和摘要统一使用 `showModalBottomSheet`，并遵循安全区和底部内边距。

## 5. 页面设计

### 5.1 智能日历

1. 顶部操作组：日期切换、`SegmentedButton` 日/周/月/甘特、手动/智能模式、字段筛选。
2. 今日状态条：能量分数、恢复缓冲、冲突数量和远端/本地状态；使用 `Card` + 玻璃组合容器。
3. 时间地图：沿用现有日/周/月/甘特数据与布局逻辑，按标签颜色显示日程块；条目点击进入标准 `Dialog`（桌面/平板）或 `BottomSheet`（手机）。
4. 救援摘要：展示最近一次接受/撤销和当前待处理冲突；使用 `ListTile`、`Chip`、`OutlinedButton` 等原生组件。
5. 紧急任务：复用现有截止时间校验、三方案比较、确认、撤销和事件写入；只调整信息层级、状态过渡和错误提示。

### 5.2 专注首页

- 当前任务使用主玻璃卡，展示标题、标签、倒计时、进度、开始/暂停/重置。
- 下一任务与时间晶体建议使用紧凑 `ListTile` 列表；加载使用统一骨架，空状态提供下一步动作。
- 能量卡显示当前能量、情绪提示和建议动作，数据来源保持现有服务。

### 5.3 其他页面

微任务、团队、目标、复盘、个人中心保留现有功能和路由，统一使用令牌化背景、容器、按钮、对话框、空状态、错误状态和主题选择入口。

## 6. 组件边界

优先组合以下 Material 3 组件：`NavigationRail`、`NavigationBar`、`AppBar`、`Card`、`ListTile`、`SegmentedButton`、`FilterChip`、`Chip`、`FilledButton`、`OutlinedButton`、`IconButton`、`Dialog`、`ModalBottomSheet`、`LinearProgressIndicator`、`CircularProgressIndicator`、`Tooltip`。

允许新增的自定义内容仅限组合层：`GlassSurface`（统一模糊/边框/语义）、`ScheduleTimeline`（时间轴布局）、`EnergyStatusCard`（服务数据映射）、`RescueSummary`（现有救援状态映射）。这些组件不直接访问网络或数据库，通过构造参数接收模型和回调。

## 7. 动效与可访问性

- 首屏模块按 40ms 间隔做最多 4 组 280-360ms 淡入上移；列表较长时保持小于 40ms 的交错间隔。
- 视图切换使用 `AnimatedSwitcher` 保持空间连续；救援方案先显示冲突定位，再展开方案卡。
- 只动画透明度、颜色、轻微位移和进度，不持续运行背景动画；避免改变布局尺寸导致抖动。
- 通过 `MediaQuery.disableAnimations` 或等效减少动效语义直接渲染最终状态。
- 所有图标使用 Material 图标，不使用 emoji；图标按钮提供 `tooltip` 和语义标签。
- 键盘焦点顺序与视觉顺序一致，焦点环可见；按钮和列表项触控区域满足平台最小尺寸。

## 8. 数据流与错误处理

页面继续调用 `AppServices.dataService`，由 `CompositeDataService` 处理远端优先和本地兜底。UI 只负责显示状态，不吞掉服务异常：

- 远端成功：显示同步状态并更新缓存。
- 网络不可用或 5xx：显示“本地模式”提示，继续允许核心日程操作。
- 4xx、鉴权失败、冲突和响应格式错误：显示明确错误，不转换为空列表。
- 批量写入失败：恢复加载控件和原界面，不生成虚假的复盘结果。

## 9. 验收与测试

- `flutter analyze` 无诊断。
- 现有 Flutter 测试与后端测试全部通过。
- 为新增组合组件补充 Widget 测试：主题切换、响应式壳层、救援状态、错误提示、减少动效。
- 在 375px、768px、1024px、1440px 宽度验证无横向溢出；至少检查手机竖屏、平板横屏和桌面。
- 独立检查浅色/深色文本对比度、焦点可见性、安全区和底部导航遮挡。
- 验证主题选择仍通过 `getThemeMode`/`setThemeMode` 持久化，未改变 FastAPI 路由和调度数据契约。

## 10. 非目标

本轮不引入第三方 UI 框架、不重写后端、不修改调度算法、不新增未实现的硬件/传感器能力，不把本地预览数据标记为实时远端数据。
