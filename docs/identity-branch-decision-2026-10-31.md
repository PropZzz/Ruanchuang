# 身份隔离分支审查结论

审查基线为云端 `main`：`44cb49f2ad65158217bc200c5a68592b6efecfea`。
历史分支 `origin/codex/member-d-client-identity-isolation` 的 tip 为 `276fc7c`，包含 8 个未合并提交，整体差异为 2425 行新增、486 行删除。

## 决定

不整体合入该分支的用户 ID 存储重设计。当前主线已有 `SessionScopedLocalPersistence.accountScope(contactAddress)`，保持账号大小写与后端相同的区分语义；改为旧分支的另一套命名空间会引入额外数据迁移和两套身份来源。

本轮单独移入仍有价值的行为修复，并按当前服务接口重写：

- 登录、注册先严格校验用户字段与非空 token，再一次性安装会话。无效响应不污染认证状态。
- `/auth/me` 返回 401 时清除远端陈旧令牌与用户缓存，保留主线“已退出”的返回语义。
- 登出即使返回 403/503 或网络异常，也清除客户端令牌及账户缓存；错误继续向上返回。
- 组合服务先阻断旧账户本地兜底，再进入游客状态。远端登出失败后仍清理本地，重新抛出原始错误及堆栈。

`test/remote_data_service_test.dart` 与 `test/composite_data_service_test.dart` 覆盖无效认证响应、到期会话、失败登出和账户切换；最终全量客户端测试通过。

## 分支保留方式

远端历史分支暂保留为设计与迁移历史，不再作为待整体合并的实现。没有通过空合并伪造祖先关系，也没有删除协作者的远端引用。因此 `git branch -r --no-merged main` 仍可能列出它；这表示 Git 祖先关系，不能再据此推断主线缺少上述修复。

原评估中“该分支不再出现在 no-merged 列表”的机械验收由本文的明确取舍与回归证据替代。后续清理远端分支时应由仓库维护者统一归档引用。
